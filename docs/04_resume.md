# 简历项目文案：基于真实M5输出

核验日期：2026-10-16。数据为用户提供的Kaggle M5公开CSV，本次使用sales_train_evaluation.csv；不是实际采购系统项目。

**项目名称：** 基于M5零售SKU需求预测的库存补货策略分析（个人数据项目）

**项目介绍：** 围绕零售商品需求计划，分析CA_1门店30个预验证历史销量较高且活跃的SKU；使用2011-01-29至2016-05-22的1,941天公开历史销量，完成商品分层、28天预测回测及采购提前期约束下的库存策略情景模拟。

**项目职责与量化成果：**

- 仅用2015-03-02至2016-02-28的364天历史筛选并分类，关联周售价计算交易价值。30个SKU历史交易价值估算合计471,623.77美元；A类17个，贡献选中样本价值80.52%；价格按销量加权覆盖率100%。该贡献率不代表整个门店份额，销售价值不是利润或采购成本。
- 比较季节性基线、28天均值和Ridge，两个28天验证窗口汇总选中Ridge；验证WAPE 40.42%，独立测试窗口2016-04-25至2016-05-22的WAPE 30.90%、MAE 6.36件/SKU日；验证与测试分别评价1,680与840个SKU日。28天递归预测不读取未来真实销量。
- 在相同模拟初始库存、7天假设提前期和历史销量冲击下对比三种补货规则。ROP模拟需求满足率97.65%、平均期末库存3,821.7件；周度覆盖策略对应92.57%、3,532.1件，说明需求满足与库存占用的取舍，不宣称真实库存改善或采购降本。
- 完成9项自动化测试、真实输出独立重算及库存/在途守恒核验；通过Streamlit六页及SKU、提前期、策略筛选检查，交付7页业务报告和离线HTML。

**简短投递版本：**

基于M5公开历史销量，对CA_1门店30个重点SKU开展ABC-XYZ分类与28天需求预测；采用两折时间验证选出Ridge，独立测试WAPE为30.90%；建立提前期约束下的模拟PO与库存台账，对比三种策略的需求满足与库存占用，并完成自动化验证与可视化报告。

## 面试时必须保留的限制

- M5无真实在手库存、供应商PO、采购成本、采购提前期和缺货标签；模拟结果不是沃尔玛实际经营绩效。
- 单门店、重点SKU、28天测试窗口不能外推为全M5或全企业效果。
- 原算法临近历史末端会缩短预测覆盖期，可能影响补货及敏感性排名；本次保留算法完成基线复现，不能据此声称长期最优政策。
- 数值可追溯到outputs/m5各表及audit/real_m5/verification.json；WAPE为自定义子样本指标，不是官方WRMSSE竞赛成绩。
